# Portfolio Standard

## Bronze — credible daily solution

Runnable code, README, tests, data source, baseline metric, chart/output and limitations.

## Silver — recruiter-quality project

Clean architecture, typing, CI, robust evaluation, packaged interface, demo, benchmark, model/data card and release.

## Gold — practitioner-quality impact project

Real stakeholder discovery, deployed workflow, monitored use, before/after evidence, ethics review, external domain feedback, contributor documentation and maintained releases.

## Case-study structure

1. Decision and stakeholder
2. Why the existing workflow fails
3. Data and provenance
4. Architecture and engineering trade-offs
5. Baseline
6. Method
7. Evaluation and failure analysis
8. Result and uncertainty
9. Responsible-use controls
10. Deployment and observed use
11. What you would change next
