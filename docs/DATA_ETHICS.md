# Environmental Data Ethics and Safety

- Minimise personal data; aggregate or anonymise where possible.
- Do not publish exact locations of endangered species, nests or vulnerable habitats.
- Treat low-cost sensor readings as measurements with calibration error, not ground truth.
- Check whether missing data systematically excludes poorer, rural or marginalised communities.
- Report model performance across relevant places, seasons and groups.
- Avoid automated punitive decisions based only on uncertain environmental predictions.
- Include a human review and appeal route for high-consequence decisions.
- Estimate computational cost for large models and justify why the complexity is necessary.
- Archive data and model versions so a result can be corrected later.
- Use respectful community participation; do not extract local knowledge without consent and benefit sharing.
