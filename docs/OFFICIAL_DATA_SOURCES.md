# Official and High-Value Data Sources

Prefer authoritative data, but always inspect methodology, update frequency, spatial resolution, missingness, revision policy, licence and whether the dataset is suitable for your intended decision.

| Source | Best for | Access |
|---|---|---|
| UN Statistics Division SDG API | official SDG goals, targets, indicators and reported observations | https://unstats.un.org/sdgs/UNSDGAPIV5/swagger/index.html |
| World Bank Indicators API | development, infrastructure, poverty, health, energy and environment indicators | https://api.worldbank.org/ |
| NASA POWER | analysis-ready solar and meteorological time series | https://power.larc.nasa.gov/docs/services/api/ |
| Copernicus Climate Data Store | historical and projected climate datasets | https://cds.climate.copernicus.eu/ |
| Copernicus Data Space | Earth-observation catalogue and processing APIs | https://documentation.dataspace.copernicus.eu/APIs.html |
| OpenAQ | global ground-level ambient air-quality observations | https://docs.openaq.org/docs |
| FAOSTAT | food, agriculture, land, emissions and related statistics | https://www.fao.org/faostat/en/ |
| GBIF | species taxonomy and occurrence records | https://techdocs.gbif.org/en/openapi/ |
| Global Fishing Watch | vessel activity and ocean-use APIs | https://globalfishingwatch.org/our-apis/documentation |
| India Open Government Data | Indian public-sector datasets across domains | https://www.data.gov.in/ |

## Dataset intake checklist

- Who collected it, for what purpose and using what method?
- What do blank, zero, suppressed, estimated and provisional values mean?
- Which populations, places, seasons or species are under-observed?
- What transformations, units and coordinate reference systems are used?
- Can the data legally be cached, redistributed and displayed?
- Could publication reveal personal information or sensitive species locations?
- What decision is this dataset fit—and unfit—to support?
