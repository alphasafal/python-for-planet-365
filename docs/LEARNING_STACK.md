# Python Learning Stack by Phase

## Foundations

Python syntax, data structures, comprehensions, functions, modules, file formats, exceptions, dataclasses, iterators, generators, context managers, logging, typing, pytest and Git.

## Data and science

NumPy, pandas, Polars awareness, SciPy, statsmodels, Matplotlib, Plotly, Jupyter, SQL, DuckDB and reproducible environments.

## Geospatial and Earth data

GeoPandas, Shapely, pyproj, Rasterio, xarray, rioxarray, Dask, STAC concepts, coordinate reference systems, spatial joins and raster/vector validation.

## Modelling and decisions

scikit-learn, time-series validation, anomaly detection, calibration, explainability, OR-Tools or PuLP, network analysis and causal-inference fundamentals.

## Products and production

Typer, FastAPI, Pydantic, packaging with `pyproject.toml`, Docker, CI, observability, caching, data/version lineage, security and MLOps fundamentals.

## World-class depth

Read source code, profile runtime and memory, contribute upstream, reproduce papers, design stable APIs, learn numerical methods, reason about uncertainty, and work with domain specialists.
