# Python for Planet — 365-Day Roadmap

This programme uses a repeating seven-day engineering cycle:

1. **Data Scout** — acquire, validate and document data.
2. **Evidence Builder** — establish baselines, uncertainty and limitations.
3. **Algorithm Engineer** — build a tested reusable Python component.
4. **Visual Storyteller** — communicate the decision through a chart, map or report.
5. **Decision Scientist** — rank, forecast, classify or optimise against a baseline.
6. **Product Builder** — deliver a CLI, API, dashboard or installable package.
7. **Impact Auditor** — reproduce, test, document ethics and publish a release.

Days 1–364 are 52 complete weekly projects. Day 365 is the public portfolio launch and next-year strategy.

## Day 365 — Public impact launch

Publish a portfolio index containing:

- the strongest 12 case studies;
- three deployed flagship systems;
- measured results and limitations;
- open issues suitable for contributors;
- a maintenance policy and next-year research agenda;
- invitations for NGOs, researchers and civic groups to collaborate.

## Definition of done for every day

A daily challenge is complete only when it has:

- a precise stakeholder and decision;
- documented data provenance and licence;
- a simple baseline;
- typed and tested Python code;
- one reproducible command;
- one result with units;
- uncertainty or limitations;
- responsible-use notes;
- a useful commit message.
